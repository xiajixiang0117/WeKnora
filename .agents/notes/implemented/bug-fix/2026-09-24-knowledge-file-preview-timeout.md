# Agent Note: 大文件知识预览请求超时

Status: implemented

## Problem

远程知识 PDF 原文件约 17 MB。服务器预览请求返回 200，但多次传输在约 30 秒时只完成部分字节；前端需下载完整 Blob 后才能展示，沿用 Axios 全局 30 秒超时会提示网络错误。

## Decision

知识文件预览单独使用 5 分钟超时。`getDown` 接受可选超时，未传入时仍遵循 Axios 全局 30 秒设置，其他下载和普通 API 的行为不变。预览仍通过认证请求取得 Blob，不把访问凭据放入 URL。

## 历史笔记审计

检索现有预览和远程文件笔记；[固定 URL 远程文件同步](../feature/2026-09-23-remote-file-datasource.md) 规定的是抓取与入库，不涉及原文件预览的客户端超时，两篇仅共享文件来源。

## Alternatives considered

延长全局 Axios 超时可以直接修复该请求，但会使所有 API 的故障等待时间增长。改成浏览器直接打开 PDF URL 能支持流式显示，但现有鉴权头不会随普通导航发送，涉及新的认证方式；此次保留受认证的 Blob 路径。

## Consequences

低速网络下预览可等待完整文件传输；失败时最长可能等待 5 分钟，且仍需在内存中持有完整 Blob。若文件传输本身中断，超时增加不能代替排查存储或网络错误。

## 验证

定向前端测试检查预览独立超时及默认超时不变；执行类型检查和笔记校验。尚未部署远程服务器。

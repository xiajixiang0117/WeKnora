# Agent Note: 恢复官方合并遗漏的本地功能契约

Status: implemented

## Problem

[合并审计](../process/2026-09-20-upstream-merge-audit.md) 已确认任务、执行轨迹、嵌入聊天、网站抓取、翻译和验证代码存在遗漏。用户要求整体修复。

## Decision

逐项移植合并前的本地功能增量，保留官方新工具、CSP 与同源鉴权实现和现有迁移编号。恢复生产调用与依赖接线，更新针对旧契约的测试，补充组件和生产入口回归覆盖。界面沿用现有主题和布局。

恢复后台任务队列和标题刷新载荷、执行轨迹采集保存与租户隔离清理、Agent 工具上下文和最终引用归集。普通问答的服务返回早于流式生成结束，因此在回答完成事件处理后保存成功轨迹；失败、取消和 panic 路径也保存，sync.Once 防止重复写入。保留官方最终回答复用对话历史的实现。

恢复嵌入页面到 composable 的 ensureSession 接线、空会话输入区、输入最小高度与按钮状态，以及网站抓取配置、创建后扫描与审核入口。每种语言补回 59 个实际使用的翻译键，并加入裁剪后保留检查；不恢复两个未使用的旧列键。保留官方凭据替换流程和后续手动 CI 决策。

## Alternatives considered

整文件恢复旧版本可以最快找回原实现，但会覆盖官方的新行为与安全修复，故只恢复经审计确认的功能增量。

## Testing

- Go internal 全包测试通过；新增生产 executeQA 入口测试覆盖完成、失败、取消、panic、流式异步保存及清空会话的租户隔离。
- 前端类型检查、构建、嵌入 composable、抓取编辑器/设置和 14 项国际化审计通过。
- SQLite 新建及升级验证通过，预期版本为当前分支已有的 26；未修改迁移文件。
- Playwright 使用模拟接口验证嵌入页在 1280、375、280 像素宽度下首次发送延迟创建会话、显示回答、输入区最小高度和无横向溢出，未出现页面异常。该检查不代替真实服务器鉴权和模型联调。
- 网站抓取表单排除资源选择器的固定高度裁剪，并保留跳过凭据步骤后的名称编辑。笔记格式及链接校验通过。

## Consequences

旧测试可能仍依赖已被官方替代的内部接口，必须验证用户行为后适配，不能只改断言消除失败。审计笔记保留历史证据，本篇与其部分重叠并承担恢复决策。

引用弹层窄屏约束已由 useCitationPopover 统一实现，无需重复恢复。鉴权测试采用官方同源请求凭据，旧父页面请求头不再作为后端授权依据。未操作共享服务器或生产数据库，生产环境仍需正常发布后验证。

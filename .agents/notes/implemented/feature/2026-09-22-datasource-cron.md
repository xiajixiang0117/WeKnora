# Agent Note: 数据源自定义定时与网页自动同步

Status: implemented

## Problem

数据源界面仅提供固定周期，网页爬取保存时还会清空调度表达式，导致已有的内容比对和失效链接清理无法定时运行。

## Decision

复用现有调度器，接受五段 cron 并兼容已有六段表达式。网页数据源可选择手动或定时；定时扫描复用网页基线及应用流程，新增和变化内容自动入库，无变化跳过。仅明确返回 404/410 的链接删除对应知识文档；目录消失但仍能访问、超时和服务器错误均不作为删除依据。删除范围不包含知识库本身。

定时网页任务需要独立于通用连接器同步，并保留扫描记录、任务作用域校验、重复触发防护及重试恢复。表达式在保存前校验，避免持久化无法执行的配置。

所有连接器共用可视化调度组件，支持按分钟、小时、日、周、月选择时间，高级模式允许直接输入表达式。通过成熟的 cron-parser 和 cronstrue 提供未来三次时间与自然语言说明。新配置记录显式时区，已有无时区表达式保持服务器时区语义，接口返回服务器时区供预览使用。

网页扫描完成后分批应用持久化变更，重试仅处理未成功的条目；队列重试尚未耗尽时保留运行中状态以避免新的调度重叠。暂停或移除调度后的重试取消执行。每个数据源每分钟使用确定性扫描主键与任务编号去重，保持现有调度器的分钟级去重边界。

## 历史审计

检索活跃笔记中的“爬取、数据源、cron”：上游合并审计仅提到数据源前端测试，与本决策无归属重叠。

## Alternatives considered

通用数据源同步路径已有成熟日志和队列，接入成本低；但网页已有独立基线和扫描变更记录，绕过它会使手动与定时行为分裂，因此复用网页流程。

目录中消失即删除能更快清除导航移除的文章，但目录可能截断或改版；用户确认仅对 404/410 删除，保留仍可访问的页面。

单独提供表达式输入框最灵活且实现简单，但要求管理员理解 cron；因此默认提供可视化控件，表达式仅作为高级入口。

## 验证

Go 定向测试覆盖表达式、专用队列调度、去重、失败恢复和实际 HTTP 200/404/410/403/429/503 的删除边界；前端测试覆盖所有连接器保存配置、非法输入与时区预览。Playwright 使用生产组件验证中文说明、周计划编辑、高级输入校验以及桌面和手机布局。前端类型检查、生产构建及多语言键校验用于验证跨文件契约。

## Consequences

管理员不需要阅读表达式，所有数据源获得一致的调度入口。自动覆盖意味着源站内容是定时网页文档的权威来源；失败链接仍会保留扫描记录。网页不展示不适用的通用冲突和删除设置。

调度遵循分钟级去重，不保证同一分钟内多次执行；按步长的表达式在小时或日期边界重置，实际时间以预览为准。后端兼容历史描述符，前端高级输入不支持 @every 间隔描述符。进程故障留下的运行中扫描继续依赖现有队列恢复机制；本次未增加分布式租约。浏览器组件验证不替代连接线上服务的完整联调，本次未部署。
